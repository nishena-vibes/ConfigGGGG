# Инструмент визуализации графа зависимостей (Вариант №26)

CLI-приложение для построения и визуализации графа зависимостей
пакетов менеджера пакетов Java (Maven). Работает без готовых
менеджеров пакетов и сторонних библиотек для получения зависимостей.

## Параметры командной строки
* `--package <имя>` — имя анализируемого пакета.
* `--repo <URL|путь>` — URL репозитория или путь к файлу тестового репозитория.
* `--test-repo` — режим работы с тестовым репозиторием.
* `--ascii-tree` — вывод зависимостей в формате ASCII-дерева.
* `--load-order` — вывод порядка загрузки зависимостей.
* `--max-depth <N>` — максимальная глубина анализа зависимостей.
* `--filter <подстрока>` — подстрока для фильтрации пакетов.

## Запуск
```
./run.sh --package ... --repo ... --max-depth ...
```

На всех этапах при запуске выводится список всех настраиваемых
параметров в формате ключ=значение. Некорректные значения
обрабатываются с выводом ошибок и кодом выхода 1.

На этапе 5 выводится PlantUML-диаграмма графа, при `--ascii-tree` —
также ASCII-дерево, при `--load-order` — порядок загрузки.
Выводятся сравнения с Maven и со штатными инструментами визуализации.
